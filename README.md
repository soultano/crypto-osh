# Crypto Osh

Сайт сообщества и ассоциации криптоэнтузиастов Узбекистана «Крипто Ош».
Три языка: узбекский (`/uz`, основной), русский (`/ru`), английский (`/en`). Голый домен `cryptoosh.uz` открывается на узбекском; на русском только если первый язык браузера русский или человек сам выбрал RU (выбор запоминается на год, `proxy.ts`).

Страницы: главная, «Новости» (`/news`, каждый день 3–5 новостей), «Курс» (`/kurs`, курс крипты в сумах), «О нас» (история, основатель, миссия), «Бизнесу» (имиджевое мероприятие: 29 млн сум до 50 гостей), «Видео» (библиотека воспоминаний), «Аукцион» (почётная порция).

## Стек

- Next.js 16 (App Router), React 19, TypeScript. Все страницы статически пререндерятся.
- Без CSS-фреймворков и сторонних скриптов: минимум зависимостей, нет трекеров.
- Фото в `public/photos` пережаты в WebP, EXIF/GPS удалены, номер машины обрезан.

## Локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

## Новости каждый день (Yangiliklar)

Каждое утро в 08:30 по Ташкенту GitHub Actions (`.github/workflows/daily-news.yml`) запускает `scripts/news/generate.mts`:

1. Читает RSS 12 крупных зарубежных крипто-СМИ (CoinDesk, Cointelegraph, The Block, Decrypt и др.) за последние 36 часов.
2. Группирует одну и ту же историю из разных изданий. Чем больше изданий о ней написали, тем она популярнее: просмотры СМИ не публикуют, поэтому охват — наша мера популярности.
3. Claude выбирает 3–5 главных историй и пишет их на узбекском, русском и английском по `scripts/news/tone.md`, с блоком «Что это значит для Узбекистана».
4. Новости коммитятся в `main`, Vercel сам пересобирает сайт, затем `scripts/news/telegram.mts` публикует их в Telegram-канал со ссылкой на сайт.

Настройка (один раз): GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Что это |
| --- | --- |
| `ANTHROPIC_API_KEY` | ключ API с console.anthropic.com (обязательно). Примерно 0,5 $ в день |
| `TELEGRAM_BOT_TOKEN` | токен бота (можно того же, что для группы). Бот должен быть админом канала с правом публикации |
| `TELEGRAM_NEWS_CHAT_ID` | канал для новостей, например `@cryptoosh` |

Без Telegram-секретов новости всё равно выходят на сайте. Запустить вручную: **Actions → Daily news → Run workflow**. Не понравилась новость: удалить или поправить её файл в `content/articles`. Чтобы стиль был точно твой, допиши 3–5 своих постов в конец `scripts/news/tone.md`.

## Курс крипты в сумах

`/kurs`: цена в долларах с CoinGecko × курс доллара ЦБ Узбекистана, страница пересобирается раз в 10 минут. Если CoinGecko начнёт ограничивать запросы, бесплатный демо-ключ кладётся в `COINGECKO_API_KEY` на Vercel.

## Курс USDT/UZS на главной

Таблица в самом верху главной (и на `/kurs`): покупка и продажа USDT в сумах у Binance, Voluto, Asterium, tcrypto, Walt и Unexpay, лучшие курсы в рамке с узором икат. Каждое утро в 08:00 по Ташкенту `.github/workflows/daily-rates.yml` запускает `scripts/rates/update.mts`: он берёт курсы из тех же публичных API, что показывают их на сайтах сервисов, пишет `content/usdt-rates.json`, коммитит в `main` и публикует таблицу в Telegram-канал (те же секреты, что для новостей).

Курсы не выдумываются: если источник не ответил или прислал число далеко от курса ЦБ, у сервиса остаётся прошлое значение, а на сайте вместо цифры кнопка «Проверить на сайте» со ссылкой на сервис. Через сутки без подтверждения цифра пропадает. Ссылки и рефки сервисов: `content/usdt-providers.json`. Запустить вручную: **Actions → Daily USDT rates → Run workflow**.

| Сервис | Источник |
|---|---|
| Voluto | `voluto.uz/api/rate-setting` (курс ЦБ + их спреды, как на сайте) |
| tcrypto | `api.tcrypto.uz/api/v1/info/calc` (котировка на 100 USDT) |
| Unexpay | `api.unexpay.uz/public/make-calc` (сейчас отдаёт заглушку 10 000, поэтому «проверить на сайте») |
| Asterium | публичного курса нет (курс даёт офис), с сайта берётся только комиссия 0,6%; в ячейках «проверить в официальном источнике» |
| Binance (CoinPay), Walt | публичного API курса нет: «проверить на сайте» со ссылкой на сервис |

## Бот группы: вступление через представление

`app/api/telegram/route.ts`. Человек нажимает «Подать заявку» в группе, бот пишет ему в личку и просит рассказать о себе. После ответа (не короче 40 символов) бот одобряет заявку и публикует представление в группе.

1. В Telegram у **@BotFather**: `/newbot` → имя и username бота → скопировать токен. Никому его не пересылать.
2. Vercel → Settings → Environment Variables: `TELEGRAM_BOT_TOKEN` (токен) и `TELEGRAM_WEBHOOK_SECRET` (случайная строка из латинских букв и цифр, 20+ символов) → Redeploy.
3. Один раз открыть `https://cryptoosh.uz/api/telegram?setup=<TELEGRAM_WEBHOOK_SECRET>`: должно быть «Готово: бот подключён».
4. В группе: **Администраторы → Добавить** бота с правом «Добавление участников». Бот напишет в группу её ID: вписать его в `TELEGRAM_GROUP_ID` на Vercel → Redeploy. Сообщение бота можно удалить.
5. В группе: **Пригласительные ссылки** → у ссылки, которая стоит на сайте, включить **«Заявки на вступление»** (или создать новую с этой галочкой и поставить её в `NEXT_PUBLIC_TELEGRAM_GROUP_URL`). Группа может оставаться частной.

## Поиск: Google и Яндекс

Сайт уже отдаёт `sitemap.xml`, `robots.txt`, hreflang для трёх языков, а страница «Бизнесу» — разметку schema.org (услуга с ценой 29 000 000 UZS и FAQ). Чтобы сайт начал появляться в поиске:

1. **Google Search Console** (search.google.com/search-console) → добавить ресурс `https://cryptoosh.uz` → способ «HTML-тег» → скопировать код в `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` на Vercel → Redeploy → «Подтвердить». Затем «Файлы Sitemap» → `https://cryptoosh.uz/sitemap.xml`.
2. **Яндекс Вебмастер** (webmaster.yandex.ru) → добавить сайт → «Мета-тег» → код в `NEXT_PUBLIC_YANDEX_VERIFICATION` → Redeploy → «Проверить». Затем «Индексирование → Файлы Sitemap» → тот же адрес, и «Переобход страниц» → `https://cryptoosh.uz/ru/business`.
3. В Вебмастере указать регион сайта: Узбекистан.

Переменные `NEXT_PUBLIC_*` вшиваются при сборке, поэтому после их изменения нужен новый деплой.

## Деплой на Vercel

1. vercel.com → **Add New → Project** → импортировать репозиторий `soultano/crypto-osh`.
2. Framework определится сам (Next.js). Переменные окружения можно не добавлять → **Deploy**.
3. **Settings → Domains** → добавить `cryptoosh.uz` и `www.cryptoosh.uz` (www настроить как редирект на `cryptoosh.uz`).

## DNS у регистратора (billur.com)

billur.com → домен `cryptoosh.uz` → управление DNS. Удалить старые A/CNAME для `@` и `www` (если есть парковка регистратора) и добавить:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | `@` | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

Vercel может показать в Settings → Domains свои значения для конкретного проекта: если они отличаются, используйте их. SSL-сертификат Vercel выпустит автоматически после того, как DNS обновится.

## Безопасность

- Строгий CSP, HSTS, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, COOP — в `next.config.ts`.
- YouTube подгружается только по клику и с домена `youtube-nocookie.com`; iframe в sandbox.
- Нет форм и сбора персональных данных, нет сторонней аналитики.
- `npm audit` перед каждым обновлением зависимостей.
